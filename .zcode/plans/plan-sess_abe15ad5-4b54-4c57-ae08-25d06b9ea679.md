## 目标与范围
改进主工作台侧边栏（`DashboardShell`）的收起/展开体验；保留现有导航、权限、桌面/平板/手机断点、主题语义 token 和 252px/76px 桌面宽度。Spark demo shell 不纳入本次范围。

## 设计方向
- 以侧栏宽度与主内容左边距的同步变化作为主要连续性动画，让整体壳体明确响应用户操作；品牌文本、导航标签和分组标题以受控的透明度/位移过渡配合显隐，避免内容突然消失或挤压。
- 动画只服务于状态变更，采用快速、平滑的进出曲线；支持 `prefers-reduced-motion`，减少空间运动但保持状态反馈和清晰的最终布局。
- 将折叠控件从侧栏底部移到品牌区右侧，作为可识别的图标式按钮；展开后提供明确文字/图标提示，收起后在窄栏中居中呈现。保留中文 `aria-label`、`aria-expanded` 与键盘焦点样式。
- 保持 ≤900px 的横向导航形态及 ≤767px 的移动 Dock 行为；这些形态仍不显示此桌面折叠控件。

## 实施步骤
1. 调整 `web/app/(dashboard)/layout.tsx` 的 sidebar 标记：将按钮放入品牌区，使用一致的内联 SVG 图标和可访问状态；移除旧底栏按钮结构。
2. 更新 `web/components/ui/Shell.module.css`：加入 sidebar/main 宽度连续性过渡、品牌与导航文案的显隐过渡、按钮新位置和悬停/聚焦/按压状态；为 reduced-motion 覆盖过渡，并检查既有断点规则不相互冲突。
3. 添加或扩展 dashboard shell DOM 测试，验证按钮可切换 `aria-expanded` 与标签、按钮在新区域可用；沿用项目现有 Vitest/Testing Library 模式。
4. 运行聚焦测试及必要的 lint/type 检查，检查改动范围，确认不会覆盖工作区已有的 Pagination 和 `.zcode*` 未提交改动。

## 验收标准
- 收起/展开时侧栏与主内容边界同步、连续地变化，标签显隐不突兀；快速重复点击不会进入错误状态。
- 按钮视觉上与现有 Mist & Deep-Sea Console 一致，位置稳定且容易发现；键盘和读屏用户可辨识当前状态与操作。
- reduced-motion 下无明显空间滑动；平板、手机断点与既有导航行为保持不变。
- 聚焦测试通过，现有主题与响应式规则没有回归。
