# 现金流量表取数口径（冻结版，待顾问签字 ④）

## 1. 总则

1. 只取**已过账（posted）凭证**的分录行；`draft/pending/void` 一律不参与。
2. 只取**现金类科目**（库存现金 `1001*`、银行存款 `1002*`、其他货币资金 `1012*`）
   的分录行；对方科目不限。
3. 现金类分录行**必须挂 `cashflow_item`**（录入时科目 `aux_flags.cashflow=true`
   则必填）；未挂项的行计入"未分类现金流"并在结账检查中告警。
4. 方向判定：现金类科目**借方 = 流入**，**贷方 = 流出**。

## 2. 项目映射（初始版，签字可调）

| 项目编码 | 项目名称 | 类别 | 方向 | 取数规则（对方科目/摘要关键字） |
| ---------- | ---------- | :---: | :---: | ------------------------------ |
| C01 | 销售商品、提供劳务收到的现金 | 经营 | 流入 | 对方 `6001/6051`（主营/其他业务收入） |
| C02 | 收到的税费返还 | 经营 | 流入 | 对方 ` tax ` 返还类摘要关键字 |
| C03 | 收到其他与经营活动有关的现金 | 经营 | 流入 | 其他经营性流入（默认兜底，需人工复核） |
| C11 | 购买商品、接受劳务支付的现金 | 经营 | 流出 | 对方 `1403/1405/5001/6101` 等 |
| C12 | 支付给职工以及为职工支付的现金 | 经营 | 流出 | 对方 `2211`（应付职工薪酬） |
| C13 | 支付的各项税费 | 经营 | 流出 | 对方 `2221`（应交税费） |
| C14 | 支付其他与经营活动有关的现金 | 经营 | 流出 | 其他经营性流出（默认兜底） |
| I01/I11 | 收回投资/购建资产相关 | 投资 | 流入/流出 | 对方 `15*/16*`（长期资产类） |
| F01/F11 | 取得借款/偿还债务相关 | 筹资 | 流入/流出 | 对方 `2001/2501/2502` |

## 3. 对账要求

- 现金流量表净额 = 现金类科目本期借贷净发生额（勾稽校验，不等则报表拒绝生成）。
- 兜底项（C03/C14）占比超过 20% 时结账检查告警，要求人工重分类。
