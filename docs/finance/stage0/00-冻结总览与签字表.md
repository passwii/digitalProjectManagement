# Stage 0 财税规则冻结闸口——冻结总览（BLF-1154）

> 父 issue：BLF-1146。审核结论（Tia）：现有系统是**项目管理 + 项目预算/支出审批/成本报表**，
> 不是以凭证为唯一入口的会计核算系统。本 Stage 为不计功能优先级的冻结闸口：
> **Stage 0 未通过，不进入 P0 编码**。本目录只含设计冻结产物，不含 P0 功能代码。

## 1. 冻结决策（后端为准，前端对照执行）

| # | 决策项 | 冻结结论 |
| --- | -------- | ---------- |
| 1 | 账套边界 | 独立 `account_books`；一切财务表以 `account_book_id` 分区隔离；`Project` 保持项目管理口径，**不得替代账套**，仅可作为辅助核算维度挂载 |
| 2 | 币种 | 仅人民币 CNY；`base_currency` 与 `currencies` 作为既有结构保留，取消多币种、汇率与调汇规划。创建账套的 API 限定 CNY 将在后续阶段落实 |
| 3 | 会计期间 | 自然月；`period_index = 年*100+月` 全局连续（含跨年），调整期记 `年*100+13`；期间状态 `open → closed → locked`，反结账倒序 |
| 4 | 科目体系 | 2022 版《企业会计准则》预置科目树；编码 **4-2-2**（一级 4 位、其下每级 +2 位，如 `1002 → 100201 → 10020101`）；只允许末级记账；停用需零余额、无子科目、无本期发生 |
| 5 | 辅助核算 | 维度：客户 / 供应商 / 部门 / 员工 / 项目 / 现金流项目；科目级开关 `aux_flags`，分录行按开关必填校验 |
| 6 | 凭证状态机 | `draft(录入) → pending(待审核) → posted(已过账)`；已过账不可改，只能**作废（未过账）/ 红字冲销（已过账）**；审核人 ≠ 制单人；过账与余额更新同一事务 |
| 7 | 凭证号 | `账套 + 期间 + 凭证号` 唯一；按期间连续编号；断号检测在过账/结账时报告 |
| 8 | 金额类型 | 全财务域 `NUMERIC(18,2)`；现有 `Budget/Expense Float` **不得进入财务域**；数量金额账另设精度（P2-D） |
| 9 | 现金流口径 | 现金流量表只取**已过账凭证**中挂 `cashflow_item` 的现金/银行类科目分录；不平/未过账不参与；详见 `05-现金流取数口径.md` |
| 10 | 税务参数 | 税率/扣除标准**配置化 + 版本化**（`effective_from/to`，同税种同日期仅一版生效，历史版不可改）；具体数值以顾问签字版为准，本文档数值均为**占位示例** |
| 11 | 结转/反结账 | 结账前置检查逐条返回阻断原因；损益结转自动生成机制凭证；反结账必须倒序、高权限、二次确认、留痕 |

## 4. 技术红线（来自审核 R0，P0 全程有效）

1. 金额统一 `Decimal / NUMERIC(18,2)`，`Float` 不得进入财务域。
2. 所有业务表以 `account_book_id` 分区隔离；凭证过账与余额更新同一事务。
3. 财务金额、状态、期间、权限判断**以后端为准**；前端只做交互校验与展示。
4. 现有 `Budget/Expense` 保持"项目管理成本域"定位；历史数据如需入账，走
   "项目成本 → 会计凭证"可核对转换（P0-C 范围），不做隐式兼容。
