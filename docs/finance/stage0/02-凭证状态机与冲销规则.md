# 凭证状态机与冲销规则（冻结版）

## 1. 状态机

```text
draft（录入/草稿） ──submit──▶ pending（待审核） ──approve+post──▶ posted（已过账）
      │                        │                                   │
      │ void（作废）           │ reject ──▶ draft（退回）          │ reversal（红字冲销）
      ▼                        ▼                                   ▼
   void（已作废）           draft（退回）              新凭证（红字，source=reversal）
```

| 状态 | 可做操作 | 禁止操作 |
| ------ | ---------- | ---------- |
| `draft` | 编辑、删除、提交、作废 | 审核、过账 |
| `pending` | 审核通过+过账、驳回、作废 | 编辑、删除 |
| `posted` | 红字冲销（生成新凭证） | 编辑、删除、作废 |
| `void` | 查阅、审计追溯 | 一切变更（终态） |

## 2. 流转规则（后端强制，前端仅做体验层控制）

1. 提交（draft→pending）：凭证借贷平衡、凭证号在期间内唯一、分录科目均为
   启用末级科目、凭证日期落在所属期间、辅助核算必填项完整，否则逐条返回错误。
2. 审核+过账（pending→posted）：**审核人 ≠ 制单人**（`ck_v_reviewer`）；
   过账前检查期间为 `open`、科目未停用、无断号跳号未说明；
   过账与余额更新**同一事务**（锁期间行 + version 乐观锁），重复/并发过账幂等
   （以 `status=pending` 为 CAS 条件）。
3. 驳回（pending→draft）：须填写驳回意见，写入审批时间线。
4. 作废（draft/pending→void）：仅未过账凭证可作废；作废须填写原因；
   作废释放凭证号但**留下断号记录**（供结账断号检测说明）。
5. 红字冲销（posted→新红字凭证）：原凭证任何字段不可改；系统自动生成
   借贷方向相反、金额相等的新凭证（`reversal_of` 指向原凭证，`source=reversal`）；
   红字凭证同样走 draft→pending→posted；原凭证标记"已冲销"关联。

## 3. 凭证号与断号检测

- 规则：`UNIQUE(account_book_id, period_id, voucher_no)`；建议编号 `记-0001` 起按期间连续。
- 断号检测脚本（结账前置检查之一）：列出期间内缺失的序号；
  缺失须有对应的 `void` 记录或冲销说明，否则**阻断结账**。

## 4. 差错更正对照表

| 发现时机 | 更正方式 |
| ---------- | ---------- |
| 未审核（draft/pending） | 直接编辑或作废重制 |
| 已过账、当期未结账 | 红字冲销后重制正确凭证 |
| 已过账、已结账 | 反结账（倒序、审批）→ 红字冲销 → 重制；或调整期凭证（须主管审批） |
| 跨年已年结 | 只能调整期更正，禁止反结上年（`locked` 期间不可反结） |

## 5. 凭证来源

`manual` 手工 / `template` 模板生成 / `import` Excel 导入 /
`auto-*` 业务单据自动生成（P1 各模块统一经此入口，禁止绕过凭证引擎直接写余额）。
导入失败须**定位到行**并整体回滚（不允许部分入库）。
