# 税务政策参数表结构与版本化机制（冻结版；数值待顾问签字 ⑤）

> 结构冻结、**数值占位**。以下税率/扣除标准均为草案示例，P0 编码不得硬编码；
> 一切计算以 `effective` 版参数 + 凭证/台账数据源为准。

## 1. 版本化规则

1. 同 `tax_type` 下日期区间不得重叠：`effective_from/to` 区间唯一有效版
   （DB 排除约束或应用层校验，P0-A 落地）。
2. 生命周期：`draft → effective → archived`；`archived` 不可改/删；
   新政策 = 新 `version` 行，不允许 UPDATE 历史版。
3. 生效须"录入 ≠ 审批"双人操作，并审计留痕。

## 3. 与核算的衔接

- P1-C 税务台账取数：销项/进项发票台账 + 总账应交税费余额，账表差异超 **1 元**
  阻断申报导出（`F-TAX-DIFF`）。
- 个税累计预扣、社保公积金基数：P1-B 按本表 `effective` 版计算，历史期间
  按当时有效版重算可复现、不可篡改。
