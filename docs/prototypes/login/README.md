# 登录页 · 液态玻璃草稿

## 文件

- `index.html`：可直接打开的新登录页草稿
- 桌面：左侧品牌故事 + 右侧登录表单，一张玻璃卡片
- 手机：单列，品牌故事压缩为顶部标题，表单在下方
- 草稿面板可切深色/浅色、默认/错误/加载态

## 保留的真实行为

- 手机号：11 位数字校验，`inputmode=numeric`
- 密码：必填，支持显示/隐藏
- 提交：加载中 → 成功反馈 → 跳转；失败显示可读错误
- 登录后：`must_change_pwd` 仍走改密页，否则进 `/dashboard`
- 不新增短信登录、扫码、第三方登录或「忘记密码」链接（后端目前没有这些入口）

## 需要确认

1. 是否保留「复杂有章 / 交付有信」这句品牌文案？
2. 左侧三步（统一台账 / 进度留痕 / 支出归集）保留还是删掉？
3. 手机号 + 密码是否仍是唯一登录方式？
4. 登录成功后是进 `/dashboard`（工作台欢迎页）还是直接进项目台账？
5. 登录页是否需要显示 PWA 安装提示，或只在登录后显示？

## 实施提醒（给后续 subagent）

- 保留 `authApi.login`、`saveSession`、`must_change_pwd` 逻辑，不要重写认证。
- 保留现有可访问性：label、`aria-invalid`、`role=alert`、`aria-busy`、`sr-only` 状态。
- 保留 `PasswordInput` 组件或复用其行为；不要引入新依赖。
- 深色/浅色都要走现有语义令牌；不要保留旧的青色科幻配色。
- 移动端注意安全区与软键盘：表单滚动、输入框不被键盘遮住。
