# Dashboard 入场动画 · 方案草稿

登录成功后，工作台如何进入画面。四个方案共用同一套页面骨架，只替换入场动效。

## 预览

- `index.html`：方案列表
- `a-rise.html`：上浮
- `b-tunnel.html`：隧道拉近
- `c-wipe.html`：玻璃擦除
- `d-orbit.html`：轨道收拢

每个页面：点「进入工作台」手动播放；停留 0.9s 自动播放；右下「重播」重复观看。

## 对比

| 方案 | 登录卡退场 | 工作台入场 | 气质 |
| --- | --- | --- | --- |
| A 上浮 | 上浮淡出 | 整体从下方托起，元素依次落位 | 克制、耐看 |
| B 隧道 | 被吸入纵深 | 从远处拉向镜头，卡片横向汇聚 | 强氛围，与隧道欢迎页同源 |
| C 玻璃擦除 | 溶解 | 磨砂玻璃横向擦过显影 | 与液态玻璃导航一致 |
| D 轨道 | 缩小旋转淡出 | 卡片从外沿轨道收拢，光晕显影 | 动势强 |

## 落地建议

- 方案 A 最稳：跨设备一致，`prefers-reduced-motion` 下直接落到最终态。
- 方案 B 与现有隧道欢迎页同源，但要避免与首页隧道叠加成“两段动画”。
- 方案 C 的擦除层是伪元素，落地成本低，注意深色下不要发灰。
- 方案 D 的位移最大，窄屏需重新计算轨道距离。
