DRAFT · DASHBOARD ENTRY

登录之后，工作台如何入场

四个方案使用同一套页面骨架，只有入场动效不同。打开任一方案即可预览：点「进入工作台」手动播放，或停留 0.9 秒自动播放；右下角「重播」可以反复看。

建议同时看两处：登录卡如何退场、工作台如何接住视线。选中后我再落到正式代码里。

RISE
方案 A · 上浮

登录卡向上淡出，工作台整体从下方托起，问候与卡片依次落位。最克制、最不容易看腻。

推荐 · 稳妥
TUNNEL
方案 B · 隧道拉近

工作台从纵深深处被拉向镜头，登录卡同时被吸入。与现有透视隧道欢迎页同源，氛围最强。

强氛围
WIPE
方案 C · 玻璃擦除

一层磨砂玻璃横向擦过画面，擦过之处工作台显影。与液态玻璃导航的气质最一致。

质感向
ORBIT
方案 D · 轨道收拢

四张入口卡从画面外沿轨道收拢到位，问候语带光晕显影。动势最明显，适合强调“进入”。

动势强
