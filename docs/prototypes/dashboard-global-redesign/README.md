# 数科云办公 Dashboard 全局改造草稿

本稿重做 Dashboard 的视觉方向，并给后续业务页提供可复用的边框、配色、排版、组件状态和响应式规则。界面以你提供的 Sable 深色案例为视觉参照，石墨深色为默认主题，边缘轮廓和数据色更鲜明。此稿只改独立原型文件，不改生产页面、接口或业务行为。

打开同目录的 `index.html` 可查看原型。顶部可切换“石墨 / 浅雾”主题和管理员 / 成员视角；项目、金额、人员名与任务为示意数据。

## 设计方向

- **产品**：项目负责人、执行成员、财务和审批人员共用的项目运营工作台，汇总项目状态、执行进度、成本、审批和交付留痕。
- **气质**：果断、精确、有秩序。
- **视觉世界**：石墨色控制台窗口；银灰边缘、亮色数据和紧凑的操作面板构成深色工作环境。
- **视觉焦点**：鲜明的六个月支出曲线、科目构成色条，以及异常项目沿“名称—进度—健康状态”贯穿的状态轴。
- **识别细节**：每个项目的状态色沿一条稳定竖线落位；项目名、进度、逾期数和健康状态保持同一列关系。

## Dashboard 信息架构

首屏帮助用户快速判断项目是否偏离、有哪些事项需要介入、支出如何变化。

1. **工作台头部**：保留“交付坐标盘”，展示统计区间和支出口径；刷新入口留在右上；只有当前用户具备审批资格且待办数大于零时才显示审批入口。
2. **关键指标**：我的项目、逾期任务、待我审批 / 未读通知、本月支出。四张独立读数面板使用亮色顶沿和清楚的外轮廓；管理员显示审批数，成员显示未读通知。
3. **项目航迹**：按异常、关注、正常、已结束排序；每行呈现名称、编号、计划结束日、逾期数、加权进度和健康状态。风险颜色落在状态线、进度值和状态文案，不铺满整张面板。
4. **需要介入**：按审批、逾期、临近到期、进度留痕呈现可定位事项。管理员视角出现审批入口，成员视角展示未读通知；两者复用相同的队列和边缘语法。
5. **数据脉冲**：左侧用一条近六个月支出曲线作为主视觉，网格保持低亮度，当前月份使用薄荷青数据点和数值标注；右侧用蓝、薄荷、琥珀、玫红表示支出科目。
6. **交付日志**：呈现近七天填报、时间、填报人、进度和所属项目，点击后进入关联业务上下文。

## 视觉系统

### 石墨与亮色数据

| 角色 | 建议色 | 使用位置 |
| --- | --- | --- |
| 外围舞台 | `#0b0d0e`，上部提亮到石墨灰 | 原型窗口外沿，提供深度 |
| 工作区 | `#171a1d` | 主内容画布 |
| 内容面 | `#1d2023` | 面板、表格、表单 |
| 抬高面 | `#262a2d` | 表头、分段选择、hover |
| 主文字 | `#eff1f0` | 标题、项目名、重要数字 |
| 次级文字 | `#b1bbc0` | 说明、列名 |
| 弱文字 | `#879298` | 日期、辅助口径 |
| 轮廓线 | `rgba(221, 233, 237, 0.12)` | 常态内容边缘 |
| 强边缘 | `rgba(221, 233, 237, 0.21)` | 面板、筛选、选中控件 |
| 电光蓝 | `#6aa9ff` | 主操作、焦点、选中入口、信息链接 |
| 薄荷青 | `#59cdb0` | 支出曲线、进度留痕和成功数据 |
| 琥珀 | `#f2c65c` | 关注、待处理、临近到期 |
| 玫红 | `#e984b8` | 科目系列与辅助数据对照 |
| 珊瑚红 | `#f17e78` | 异常和逾期 |

颜色跟随信息职责：工作台表面保持石墨层次，鲜艳颜色集中在图表系列、状态、主要操作和当前焦点。不会把全屏做成霓虹灯牌。

### 边框高光与表面

- 普通面板使用 1px 清楚的银灰轮廓，顶部加一条轻微内反光，面板边缘在深色背景上保持完整可见。
- 指标面板用 1px 外框、2px 彩色顶沿和浅色内高光区分主题；颜色只取对应指标或语义色。
- 当前导航使用蓝色描边、淡蓝底面和内侧高光；键盘焦点使用独立的 2px 外环。
- 预警、逾期和成功项目使用 3px 状态线；状态徽标采用深色半透底和较亮文字。
- 外发光只出现在图表数据点、数据线和状态标记等信息焦点；普通面板不加彩色光晕。
- 桌面应用窗口、面板、控件分别用 20px、12px、8px 圆角；状态标签维持更紧凑的 5px 圆角。

### 字体与对齐

- 中文使用项目的 Noto Sans SC / PingFang SC 等无衬线字体栈；金额、项目编号、日期和百分比使用等宽数字。
- 页面标题约 28px，区块标题 14–16px，正文 12–14px，元数据 10–11px；数值使用 tabular figures。
- 图标统一 18px 线条；导航图标和文字固定列对齐。
- 表格金额与比例右对齐；表头、正文、状态、操作列拥有稳定的列关系；信息不足时提供留白，不把列挤成断行。
- 不用图标填满每张卡片；亮色和边缘效果作为数据编码，不作为重复装饰。

## 通用组件与状态

- **筛选工具带**：搜索、筛选、清除和主操作在同一工作带上；宽度不足时按优先级换行。
- **表格**：表头使用抬高石墨面和清楚的边界；桌面数据行保持一致行高；hover、选中、通知定位和键盘焦点均有持续可见的边缘反馈。
- **状态徽标**：统一尺寸和圆角；正常、关注、异常、结束状态同时保留文字和图形标记；角标仅在确有待办时出现。
- **Dialog / Drawer**：统一外轮廓、顶边高光、页脚按钮和焦点环；多字段编辑使用 Drawer，短操作确认使用 Dialog。
- **表单**：字段标签显式展示；错误边框、错误文字和恢复方法同步；保存中的按钮说明当前状态。
- **加载 / 空 / 错误 / 权限**：骨架在深色面上保持可读；空态提供下一步；失败态说明数据是否过期并提供重试；无权限态说明模块未分配。
- **通知 / 审计 / 变更时间线**：节点线用薄荷青或语义色；时间和实体名对齐；审计记录链接到资源详情，不伪装成待办。

## 响应式规则

- **桌面（≥1121px）**：中心应用窗口，约 240px 侧栏和宽工作区；Dashboard 项目与介入并排，支出曲线保持主视觉。
- **平板（768–1120px）**：侧栏收成图标轨道；主区块纵向堆叠；趋势图保留宽度，数据表维持列关系。
- **手机（≤767px）**：隐藏桌面侧栏，底部保留现有五位 Dock（工作台 / 项目 / 资产 / 报表 / 我的）和设备安全区；指标两列，事项与项目单列；触控目标不少于 44px。
- **手机业务入口**：进度和支出可从工作台 / 项目上下文进入；审批、通讯录、财务、友商和系统管理继续由“我的”面板承接。

## 动效与主题

- 默认打开石墨深色主题；浅雾主题作为可选预览。两种主题共享结构和颜色职责。
- hover、焦点、菜单、状态更新使用短过渡；不循环脉冲非实时数据，不动画布局尺寸，尊重 `prefers-reduced-motion`。
- 图表线和当前数据点允许有轻微高亮；普通内容面板依靠轮廓与层级，不持续发光。
