# 全局前端视觉与动效打磨设计

- 日期：2026-10-28
- 状态：设计已获用户确认，待用户审阅文档

## 目标与范围

打磨数科云办公的已登录工作台与登录页。工作台范围包括首页、业务模块及其共享组件；登录页保留独立的视觉身份并单独精修。此次以共享基础层为主，不逐页重排业务布局。

目标是在保留现有品牌与产品行为的前提下，修正用户指出的暗色模式正文设计感与层级问题，并建立覆盖全站的动效节奏，使页面更专业、清晰且有活力。

## 设计方向

沿用 DESIGN.md 的“雾白与深海蓝”视觉方向：深海蓝与雾白分别承载暗、亮工作面，青色继续表示信息信号和焦点，酸橙继续表示主要操作或完成状态。保留直角、细边界、中文无衬线和既有组件尺寸原则，不引入另一套品牌色或装饰性圆角系统。

重点校准暗色正文的可读层级和表面关系，包括主文字、辅助文字、表格行与表头、表单控件、菜单、对话框及状态徽标。深浅主题都需要复核，确保主题切换只更换语义映射，不改变组件职责、信息顺序或可见交互状态。业务文案、数据、页面信息架构和工作流程保持原样。

## 动效策略

以共享动效基础层统一编排页面与组件反馈。动效覆盖导航切换、页面内容呈现、筛选结果、表格行反馈、数据更新及浮层状态；悬停、按下、焦点与提交等高频操作保留快速响应，避免等待动效完成才能继续操作。

优先复用现有动效令牌、组件和机制，按场景建立一致的节奏与错峰规则，不在页面中散布无治理的时长或关键帧。动画不得隐藏必要内容或造成版面跳动。`prefers-reduced-motion` 与 `?static=1` 下移除非必要运动并直接呈现稳定终态，保留状态变化本身。

## 登录页

保留登录页独立视觉身份与现有内容、认证行为、错误语义、密码显示操作、路由跳转和移动端安全区约束。此次只精修其视觉表达、表单层级与合适的动效，不改变登录 API、会话保存或路由门禁。

## 实施边界

- 以全局设计 token、共享样式和通用动效组件为主，业务页面沿用当前结构与交互。
- 不改后端接口、数据模型、权限逻辑、审计行为或业务文案。
- 登录、Spark 和 stream-monitor 是独立视觉区域；本次只纳入登录页，不把工作台主题强行覆盖到演示站。
- 颜色、动效时长、缓动遵循仓库现有设计令牌和源码守卫。

## 验收

选取工作台首页和一个高频业务页，检查暗色与浅色主题、桌面与移动宽度，以及真实数据密度下的正文、表格、输入控件、浮层和状态表现；另检查登录页的桌面与移动布局。确认导航、筛选、分页、表单和浮层行为不变，动画无内容隐藏或布局跳动，减少动态偏好和静态截图模式下页面仍呈现正确终态。

设计文档只定义目标与边界。具体受影响的共享组件、token、动效实现和代表页面，将在实施计划中结合当前代码结构确定。
