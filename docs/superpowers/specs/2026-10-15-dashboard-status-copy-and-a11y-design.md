# 工作台状态文案直白化与键盘可达性修复设计

> 日期：2026-10-15
> 状态：方向已确认，待实施
> 范围：`/dashboard` 的状态与操作文案；项目列表表格行的键盘入口；自绘 Select 弹层的可访问名

## 背景

本轮来自一次系统化前端 Review 的结论。Review 未发现阻塞级缺陷，但确认两类需要收敛的问题：

1. 工作台首页把「加载中 / 刷新失败 / 陈旧数据」等系统状态表达成科幻隐喻（「校准中」「链路未完成校准」「刷新坐标」），用户需要先把隐喻翻译成实际状态，才能判断数据是否刷新、是否已过期。
2. 项目台账的桌面表格行只响应鼠标点击，键盘用户无法通过行级入口进入详情。

Review 最初还怀疑自绘 `Select` 的标签关联失效。复核后用 `dom-accessibility-api` 在真实 DOM 结构上实测：`Field`（`<label>` 包裹）与 `<label>` 直接包裹两种写法都能正确计算出可访问名。全库 59 处 `Select` 中，23 处使用显式 `aria-label`，36 处依赖包裹式 `<label>`，没有完全无名的实例。因此该问题收窄为弹层 `listbox` 自身缺少可访问名。

## 目标

- 工作台首页的状态、操作与错误文案在保留产品视觉与分区命名的前提下变得直白可读。
- 键盘用户可以在项目台账桌面表格中用与鼠标等价的方式打开项目详情。
- 自绘 `Select` 展开后的 `listbox` 具备可用的可访问名。

## 非目标

- 不改变工作台视觉样式、颜色、排版与动效。
- 不重命名首页标题「交付坐标盘」及「项目航迹 / 需要介入 / 数据脉冲」等分区名称。
- 不修改其余 6 处同模式的点击行（通讯录、友商、管理员用户列表、管理员日志、项目详情进度行、应收面板行）；本轮只修项目列表，其余记入后续整改清单。
- 不引入第三方组件库，不改变接口、权限语义或字段名称。
- 不调整 `Field` 的 DOM 结构，不处理提示文字进入可访问名的问题（见「已记录但不处理」）。

## 二、项目列表表格行键盘入口

在 `web/app/(dashboard)/projects/ProjectsListContent.tsx` 的操作列新增一个「查看」按钮：

- 位置在「编辑」之前，与现有按钮同为 `btn-ghost btn-xs`。
- 点击时 `event.stopPropagation()` 后调用 `onSelect?.(p)`，与整行点击进入同一个详情抽屉。
- 现有整行 `onClick`、`title="点击查看详情"` 与 `clickable-row` 样式保持不变，鼠标行为无变化。

这样做的理由：`<tr>` 不具备可聚焦语义，若给它加 `tabIndex`，键盘用户需要逐行 Tab 经过表格，且会破坏表格的读屏结构。在操作列提供一个真实按钮，既保留表格语义，也让键盘入口与鼠标入口在行为上完全等价。不新增列，不改变列宽与行高。

## 三、自绘 Select 弹层可访问名

在 `web/components/ui/Select.tsx` 的展开弹层上，让 `listbox` 复用触发器的可访问名：

- 触发器已有名字的来源有两种：显式 `aria-label`，或外层 `<label>` 包裹。
- 弹层当前写法是 `aria-label={ariaLabel}`，包裹式写法下为空。
- 改为在弹层上使用同一个 `ariaLabel`，并在为空时回退到触发器的可访问名（读取触发器元素上已计算的 `aria-label`，或包裹式 `<label>` 的文本）。

实现要求：回退逻辑必须在不改变现有显式 `aria-label` 行为的前提下工作；不得为了取值而改动触发器的 DOM 结构或视觉。

## 四、测试

- `web/lib/dashboardPage.dom.vitest.test.tsx`：更新 4 处文案断言（刷新按钮名称、刷新中状态、陈旧数据横幅文本），并确认原有加载、重试、`aria-busy` 断言仍成立。
- `web/lib/` 下新增或扩展项目列表 DOM 测试：
  - 桌面表格存在「查看」按钮，点击后调用 `onSelect` 进入详情。
  - 「查看」按钮可通过键盘聚焦与激活。
- 新增 Select 可访问性断言：在 `Field` 包裹的真实结构下，触发器可被 `getByLabelText` 找到，且展开后的 `listbox` 具有非空可访问名。

## 五、验收标准

- 首页在加载、刷新、刷新失败、首次加载失败四种状态下，文案均为直白中文，不含「坐标 / 校准 / 接入 / 链路」等隐喻表达；页面标题与分区命名未变。
- 项目台账桌面表格中，键盘用户可聚焦并以 Enter/Space 激活「查看」按钮打开详情；鼠标点击整行行为不变。
- 自绘 Select 展开后，`listbox` 在 `Field` 包裹式与显式 `aria-label` 两种写法下均有非空可访问名。
- 深浅主题、桌面与移动布局无视觉变化（本轮不改样式）。
- 现有测试全部通过：`npm run test`（`test:unit` + `test:motion`）与 `npm run lint` 无新增错误。
- 最终差异只包含本设计范围。
