# 登录页科幻身份握手设计

## 目标

把 `/login` 从沉闷的商务双栏登录页重塑为「地面站捕获 · 身份握手」体验：用户在几秒内知道这是数科云办公的入口，同时通过可理解的扫描、锁定和握手反馈，感受到项目治理工作台的精密、可信与持续推进。

## 保留的产品事实

- 产品名称与中文业务文案仍为“数科云办公”“数字化项目运营”“项目协同 · 交付管理”“复杂有章，交付有信”。
- 手机号账号、密码、密码显示切换、错误校验、错误提示、登录接口、会话保存、首次改密跳转和登录后跳转全部保持不变。
- `/change-password` 继续复用登录表单的基础样式，但不强制复用登录页的科幻舞台。
- 手机端继续使用 `100dvh`、安全区、可滚动表单与不小于 44px 的触控目标。

## 视觉世界

### 核心隐喻

地面站正在捕获一颗承载项目事实的卫星。页面左侧是轨道扫描场，右侧是身份控制台；用户输入账号与密码，等同于向工作台发起一次身份握手。

### 材料与色彩

- 深黑蓝背景作为真实操作环境，而不是纯黑装饰。
- 冷青色作为链路、扫描和焦点；酸橙色只表示已锁定/已连接；琥珀色表示等待或注意；红色只用于失败状态。
- 细线、坐标刻度、轨道环、噪点和微弱辉光构成系统语言；不使用大面积玻璃卡片、渐变文字或无语义的装饰网格。
- 右侧控制台使用深色实面与高对比边界，避免白色商务卡片继续主导首屏。

## 首屏结构

1. 全屏深色舞台，左侧轨道捕获场、右侧登录控制台。
2. 左上保留品牌与产品定位，右上显示“SECURE LINK / NODE 07”类系统状态。
3. 捕获场显示轨道环、扫描线、锁定标记与三条业务链路：统一台账、进度留痕、支出归集。
4. 控制台显示“登录管理工作台”、手机号和密码字段、错误状态与“进入管理平台”按钮。
5. 底部以低对比度短句收束，不增加虚构数据、客户或安全承诺。

## 动效语法

- 初始进入：背景星点、扫描线、轨道与控制台错峰显现；内容在默认状态下可读，不依赖动画才能出现。
- 捕获循环：扫描光束以低频率横扫，轨道节点有微弱呼吸，状态灯保持节奏而非持续闪烁。
- 字段聚焦：捕获场的目标框切换到当前字段，相关业务链路升亮；表单控件出现清晰焦点环。
- 提交验证：按钮进入验证态，链路光束沿轨道移动，文本变为“正在建立安全链路…”；成功由亮起的连接节点反馈，失败由链路断开与错误提示反馈。
- 减少动效：保留静态轨道、状态色、焦点和文本，移除循环扫描、位移、闪烁与模糊过渡。

## 交互与状态

- 手机号输入仍只接受数字并限制 11 位。
- 空值、格式错误、错误凭据和接口失败继续使用现有中文错误语义。
- 控件禁用时保留结构与可读性，不用纯透明度隐藏内容。
- 密码显示按钮保持原有语义与 `aria-pressed`。
- 所有交互可用键盘完成，焦点顺序与 DOM 顺序一致。

## 响应式

- 桌面端使用双区域布局，捕获场为主叙事，控制台保持稳定宽度。
- 980px 以下改为纵向单舞台，保留捕获场的部分轨道语汇。
- 767px 以下以移动端为主：舞台缩短、轨道降低密度、控制台占据可用宽度；表单在视口中保持可见，软键盘抬起时允许滚动。

## 实现边界

- 只修改登录页与登录页专属样式；不改认证 API、会话协议或业务页面。
- 优先使用 CSS transforms、opacity 和有限的 box-shadow，避免持续触发布局计算。
- 复用现有 Framer Motion 的减少动效能力；不新增重型依赖。
- 视觉预览与真实登录页使用同一套组件与样式，避免“预览是一套、生产又是一套”。

## 验证
