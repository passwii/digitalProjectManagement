# 全站自绘下拉与菜单优化设计

> 日期：2026-09-28
> 状态：方向已确认，待设计文档复核
> 范围：工作台的下拉选择、菜单和项目删除按钮细节

## 目标

将工作台内可见的原生选择菜单统一为项目自绘控件，并修正项目删除按钮的 hover 边框颜色。现状盘点发现 58 个 `<select>` 分布在 25 个 TSX 文件；其中包括项目筛选、业务表单、移动端页面分区切换和 NebulaCloud 演示页。另有一处财务页移动端操作菜单使用 `<details>/<summary>`。

日期、月份、时间、文件、复选框和单选框继续使用系统控件。业务值、URL 筛选、权限判断、表单提交和删除确认流程保持原有语义。

## 视觉方向

沿用「全站交付控制台」：直角边框、细分隔线、深蓝操作环境、青色交互信号和酸橙主动作；浅色主题通过现有语义 token 呈现同一层级。下拉触发器和选项浮层跟随当前界面的主题色，不增加独立配色或圆角体系。

浮层复用 `--card`、`--line`、`--shadow-float`、`--row-hover`、`--brand` 与 `--brand-soft` 等 token。当前已经自绘的账号菜单和可搜索项目选择器作为行为及视觉参照；NebulaCloud 演示页面沿用其已有的局部色彩约定。

## 组件与行为

### 共享 Select

- 新增项目内共享的自绘 Select 组件及样式，覆盖全部 58 个现有原生 `<select>`。
- 选项以 JSX `<option>` 声明，使静态选项、动态映射、空值和禁用项保持易读；组件向业务回调输出字符串值，调用方继续负责原有状态更新。
- 控件保留 `value`、`defaultValue`、`name`、`required`、`disabled`、`aria-label`、`className` 等实际用到的属性；隐藏表单值同步到原生表单提交，必填校验失败时焦点回到可见触发器。
- 触发器使用项目按钮与输入框 token；列表浮层使用 listbox/option 语义，显示当前值、禁用状态和键盘活动项。
- 选项较长时允许换行或截断并保留完整可读名称；浮层受视口高度限制，空间不足时翻转到触发器上方，避免被页面或弹窗滚动容器裁切。
- 支持点击与触控打开；键盘支持方向键、Home、End、Enter、Space、Escape 和首字母检索。关闭后焦点保留在触发器，点击浮层外关闭。
- 桌面控件保持当前紧凑尺寸；移动端触发器和选项满足至少 44px 触控高度。遵循 `prefers-reduced-motion`。

### 菜单与特殊选择入口

- 将财务页移动端「账套操作」的 `<details>/<summary>` 替换为项目样式的自绘操作菜单，保留原有操作项和回调。
- `MotionTabs` 的手机端页面分区切换改用共享自绘选择控件；桌面 tablist 与面板过渡保持原样。
- 账号菜单及项目搜索选择器已经有自绘实现，本轮检查其颜色、焦点、层级和移动端尺寸，使它们与新控件遵循同一视觉规则；保留主题切换、搜索、分页和现有键盘操作。

### 项目删除按钮

项目列表的桌面行、移动卡片及详情入口继续保留原有软删除和两步确认流程。删除按钮 hover/focus 使用语义危险色边框与浅红背景，文字和图标维持危险色；默认态保持轻量，不改动编辑按钮或其它幽灵按钮的品牌色状态。

## 分批迁移

1. **共享基线**：实现 Select 与菜单浮层，迁移项目筛选、项目表单、手机端页面分区和财务移动操作菜单；同步修复项目删除按钮。
2. **业务表单**：按财务/成本、进度、资产、通讯录、报表、商机、管理和演示页面迁移剩余 Select，保留每个页面原有值与更新逻辑。
3. **全局收尾**：扫描所有生产 TSX 中的原生 `<select>` 与原生操作菜单，检查深浅主题、桌面与 iPad/手机视口、键盘和触控，并修复扫描出的实际问题。

## 验收标准

- 生产组件不再渲染原生 `<select>` 选项弹层，也不再用 `<details>/<summary>` 承载该操作菜单。
- 全部原有筛选、表单选择、必填提交、URL 状态、菜单回调与删除确认行为保持一致。
- 深浅主题下，触发器与浮层使用当前主题 token；菜单不被弹窗、滚动区或视口边界裁切。
- 鼠标、键盘和触控均能完成选择；焦点、选中项、禁用项和错误状态可辨识。
- 项目删除按钮在 hover/focus 时呈现红色边框和浅红底色，桌面列表与移动卡片表现一致。
- 最终差异只包含本设计范围，且人工检测器对改动的网页目标运行一次。

## 非目标

- 不替换日期、时间、文件、复选框或单选框控件。
- 不引入第三方组件库，不改变业务 API、权限语义、字段文案、项目删除服务端行为或设计系统总体配色。
